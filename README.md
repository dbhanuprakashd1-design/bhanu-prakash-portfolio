# Bhanu Prakash —  Portfolio

A production-style portfolio built with Next.js, Tailwind CSS, TypeScript and client-side animation.

## Included

- Responsive navigation with mobile menu
- Animated hero section
- Animated code-card UI
- Scroll reveal animations
- Animated skill bars
- Infinite technology marquee
- Experience timeline
- 5 project showcase cards
- SEO metadata
- robots.txt
- sitemap
- Responsive mobile/tablet/desktop layouts
- Vercel-ready Next.js structure

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000


## Deploy

Push the folder to GitHub and import the repository into Vercel.

This portfolio intentionally uses CSS animations and lightweight client-side JavaScript instead of heavy animation libraries, keeping the page fast and SEO-friendly.
